# GitHub Projects Overview

## 🧠 Machine Learning / Data Science

**Human-Decision-Making-Under-Uncertainty-Project**: ML model predicting human choices in gambles, based on Cumulative Prospect Theory (Tversky & Kahneman) and the c13k dataset.
Tech: Python, pandas, scikit-learn, LightGBM, Optuna, SHAP

**Age-and-Gender-Distortion-Project**: Statistical analysis of age/gender bias in GPT-2 generated text (correlation, regression, ANOVA).
Tech: Python, pandas, statsmodels, scipy, seaborn, plotly

**Doughnut-of-Social-and-Planetary-Boundaries-Project**: Reproduces the Doughnut Economics model with custom charts, including a hand-built interactive doughnut plot.
Tech: Python, pandas, matplotlib, numpy, ipympl

## 🧮 Optimization Algorithms

**Capacitated-Team-Orienteering-Problem-CTOP-**: Vehicle routing/delivery optimization solved with greedy construction, local search, Iterated Local Search, and Large Neighborhood Search.
Tech: Python
